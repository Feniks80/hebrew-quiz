# Пробелы в начальной лексике (уровень A1–A2, ульпан алеф)

Проверены колоды для начинающих: zero, everyday, health, home, city, people, shopping
(около 650 слов). Для сравнения взят ориентир «около 1000 самых нужных слов» ульпана алеф.

## Главный вывод
Начальные колоды тематические: врач, аренда, ремонт, эмоции. Слов-«каркаса», из которых
строится любая фраза, в них почти нет. Многие такие слова (дни недели, местоимения, предлоги,
наречия, числа) есть только в колодах engineer и b2. Пожилая начинающая ученица их не открывает.
Поэтому около 200 из 378 слов новой колоды core повторяют слова из engineer/b2, но для
начинающей это новые слова. Ни одно слово core не повторяет начальные колоды.

## Чего нет или почти нет
1. **Числа после 10.** В zero только 1–10. Нет 11–19, десятков, 100, 1000. Без них не понять цену,
   номер автобуса, этаж, время.
2. **Порядковые числительные.** Нужны для этажей, очередей, дат и выражений вроде «первый раз».
3. **Дни недели, месяцы, времена года.** Совсем нет. В Израиле неделя начинается
   в воскресенье, и дни называются по номерам. Без этого не записаться к врачу и не назначить встречу.
4. **Время и часы.** Есть только «сегодня / завтра / вчера». Нет «который час?», «сейчас»,
   «потом», «рано / поздно», «утром / вечером», «минута».
5. **Погода.** Есть «солнце, дождь, снег». Нет «жарко», «холодно», «хамсин», «градусы», «облачно»,
   то есть того, о чём говорят каждый день и что объявляют по радио.
6. **Цвета.** Нет оранжевого, фиолетового, коричневого, серого, голубого и других.
7. **Вопросительные слова.** Есть только «где?» и «сколько?». Нет «что? кто? когда? почему?
   как? куда? откуда? какой?». Без них не задать вопрос.
8. **Местоимения.** Есть только «я, ты (м/ж), он, она, мы». Нет «вы», «они», «это / эта / эти»,
   притяжательных (שלי, שלך…), форм «мне / меня» (לי, אותי), а также «кто-то», «что-то»,
   «никто», «ничего», «все», «всё».
9. **Предлоги и союзы.** Их нет совсем: с, без, для, у, до, после, между, рядом, но, или, если,
   потому что, поэтому, только. Это самая серьёзная дыра: без них речь сводится к отдельным словам.
10. **Частые прилагательные.** В everyday 10 слов. Нет пар-антонимов «длинный / короткий»,
    «тяжёлый / лёгкий», «дорогой / дешёвый», «открыто / закрыто», «чистый / грязный»,
    «полный / пустой».
11. **Частые наречия.** Нет «очень», «немного», «ещё», «уже», «всегда», «никогда», «иногда»,
    «много», «вместе», «быстро», «медленно», «конечно», «может быть».
12. **Вещи в кармане, документы, деньги.** Есть «теудат зеут» и «паспорт». Нет «кошелёк»,
    «очки», «зарядка», «кредитная карта», «наличные», «сдача», «цена», «чек», «банкомат»,
    «шекель», «права», «бланк».
13. **Еда.** Нет «завтрак / обед / ужин», «суп», «салат», «бутерброд», «пита»,
    «хумус», «сахар», «сметана», «творог», «колбаса», «каша», «гречка».
14. **Кухня и мебель.** Нет «чайник», «плита», «чашка», «миска», «морозилка», «шкаф»,
    «ящик», «кондиционер», «вентилятор», «пульт».
15. **Одежда.** Нет «одежда», «футболка», «свитер», «куртка», «шорты», «носки» в ктив мале,
    «тапочки», «шарф», «пижама», «размер», «карман».
16. **Место и направление.** Нет «направо», «налево», «прямо», «здесь», «там», «наверху»,
    «внизу», «внутри», «снаружи», «близко», «далеко», «вход», «выход», «этаж».
17. **«Как я себя чувствую».** Есть прилагательные «усталый», «голодный», но нет готовых фраз
    «мне холодно / жарко», «мне больно», «болит голова», «я хочу пить», «у меня температура».
    Нет и женских форм, а основная ученица — женщина.

## Попутно найденные ошибки в колоде everyday
Часть слов записана без матерей чтения. В повседневном иврите так не пишут: אדם (вместо אדום —
«красный», к тому же אדם значит «человек»), כחל, צהב, שחר, ורד, שלחן, מטה (кровать — מיטה),
לישן, לקרא, לכתב, דאר, חלצה, נעלים, אזן, צפור, אופנים, ארז, עגבניה. В zero стоит שנים вместо
שניים. Эти слова стоит исправить отдельной правкой.

## Что закрывает колода core
18 категорий, 378 слов: все 17 областей выше. У фраз о самочувствии есть женские формы; если
она пишется так же, как мужская (חולה, רוצה), её произношение дано в примечании.
