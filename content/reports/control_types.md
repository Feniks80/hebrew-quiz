# Типы контроля: механика, статистика, экзамены, доступность

Профили: **E** = пожилой новичок (планшет, крупно, без спешки, без наказаний); **A** = продвинутый (B1/B2, хочет скорость и глубину).
Общие принципы (исследования): активное припоминание > узнавание; интервальные повторения (Anki/Leitner) дают самый большой выигрыш; немедленная обратная связь; ошибка = повод показать верный ответ и вернуть слово в очередь, а не штраф; ~80-85% успешных ответов оптимально для мотивации (Wilson 2019).

## 1. Решённые типы упражнений

**Карточки «знаю / не знаю»** (самооценка).
- E: 8 карточек в раунде. Переворот по тапу, две огромные кнопки «Знаю» (зелёная) / «Ещё раз» (жёлтая, не красная). Звук и иврит с огласовками на лицевой стороне, перевод на обороте. Нет таймера.
- A: 15-20. Четыре кнопки как в Anki: Снова / Трудно / Хорошо / Легко (интервалы 10 мин / x1.2 / x2.2 / x3.5). Иврит без огласовок по настройке.
- Дистракторов нет. Скоринг: «Знаю» = 1 балл, «Ещё раз» = 0, но слово возвращается в конец раунда один раз. Защита от самообмана: каждые 5-я «знаю»-карточка переспрашивается как выбор из 4 (тихая проверка); если не прошла, самооценка не засчитывается.
- Фидбек: после «Ещё раз» просто показать ответ и озвучить, без слова «ошибка».

**Выбор из 4 (оба направления).**
- E: 8 вопросов, 4 варианта (на ранних темах 3), кнопки на всю ширину >=72 px. Направление иврит -> русский первым; обратное только когда слово набрало 2 верных подряд. Неверный вариант серый и гаснет, можно выбрать снова (без штрафа, но первая попытка пишется в статистику). После второй ошибки правильный вариант подсвечивается и озвучивается.
- A: 12-15 вопросов, 4-5 вариантов, оба направления вперемешку, один шанс. Опционально таймер 10 с (спринт, см. п.2).
- Дистракторы: из той же темы и той же части речи, того же рода/числа; для иврита визуально/фонетически близкие слова (שולחן/שלחן-подобные, корни одного бинъяна, ב/כ, ד/ר); для русского перевода близкие по смыслу (не абсурдные). Минимум один дистрактор из «путаемых ранее» (confusion list пользователя: что он выбирал вместо верного). Не использовать «все/никакой из перечисленных». Порядок случайный, позиция правильного не повторяется 3 раза подряд.
- Скоринг: с первой попытки = 1, со второй = 0.5 (E) / 0 (A). Фидбек: зелёная галочка + слово прозвучало; при ошибке «Это было: X — Y».

**Аудирование «услышал -> выбрал».**
- E: 6 заданий; кнопка «Прослушать» огромная, неограниченно, есть «медленно» (0.75x). Варианты: русские переводы (не иврит-написание, чтобы не требовать чтения). Автовоспроизведение один раз при открытии.
- A: 10 заданий; варианты — ивритское написание без огласовок, дистракторы-минимальные пары по звуку (שם/סם, חם/כם, עין/אין) или фраза: слышит предложение, выбирает смысл. Скорость 1.0, иногда быстрая.
- Скоринг как у выбора; дополнительно считать «слух» отдельно от «чтения». Фидбек: при ошибке проиграть оба варианта подряд с подписями.
- Условие: аудио TTS/записи иврита должны быть проверены на качество (ударения, ה/ח/ע); плохой TTS вреднее отсутствия.

**Сборка слова из букв / фразы из слов.**
- E: слово из 3-4 букв (плитки >=64 px, лишних плиток нет или 1); фраза из 3-4 слов, без лишних. Показывать русский перевод и играть звук. Плитка встаёт на следующий слот по тапу (не drag); тап по слоту возвращает плитку. Для RTL слоты заполнять справа налево, стрелка-подсказка. Огласовки на плитках включены. Неправильная плитка просто не «прилипает» (мягкая тряска), без счётчика ошибок; подсказка «первая буква» после 2 неудач.
- A: слово 4-7 букв + 2-3 лишних плитки-ловушки (ב/כ, ד/ר), без огласовок, без звука по умолчанию; фраза 5-8 слов + 2 лишних слова (неверный род/форма). Можно перетаскивание.
- Скоринг: 1 балл за чистую сборку; -0.5 за использованную подсказку; не более 2 исправлений. Фидбек: при ошибке показать собранное vs верное с подсветкой различий.
- Раунд: 5 слов (E), 8 (A).

**Подбор пар (match).**
- E: 4 пары в раунде, две колонки (иврит справа, русский слева), тап-тап; верная пара остаётся зелёной, неверная — мгновенно сбрасывается. Без таймера и счётчика ошибок.
- A: 6-8 пар, иврит без огласовок, русские варианты перемешаны, виден таймер как личный рекорд (не как наказание).
- Пары подбирать из одной темы + 1-2 пары-ловушки схожих по написанию. Скоринг: пара без ошибки = 1, с ошибкой = 0.5. Фидбек: по окончании показать пары, где ошибся, с озвучкой.

**Финальный экзамен по теме** и **работа над ошибками** — п.4 и п.2. **Статистика** — п.3.

**Огласовки (toggle).** E: по умолчанию ВКЛ везде, включая слова на плитках; A: по умолчанию ВЫКЛ в экзаменах, ВКЛ в обучении. В экзаменах уровня B1/B2 огласовок нет принудительно. Переключатель — одна кнопка «ְ» в шапке, запоминать выбор.

**Уроки грамматики + квиз.** Урок: 1 правило на экран, 3-4 примера с озвучкой, потом 5 заданий (E) / 8 (A): 60% выбор правильной формы, 20% «выбери пропущенное», 20% сборка фразы. Объяснение по-русски, без терминов (сначала «мужской/женский», потом «биньян»). Фидбек на ошибку: «Здесь нужна женская форма, потому что стол — слово женского рода» (правило, а не просто ответ). Проходной порог 80%, повтор без ограничений.

**Рукописные буквы.** Крупный шрифт-образец рядом с рукописной формой; задание «какая это буква» с 4 вариантами печатной формы; в E только 4-6 букв за раунд, группами по похожести, начиная с различимых; в A — скоропись и неразборчивые образцы. Трассировка пальцем — опционально (красиво, но дорого, оценить трудно).

**Колода «вывески».** Фото/рисунок вывески -> выбор значения (E, 6 заданий) / чтение без огласовок + смысл (A, 10). Дистракторы — другие вывески той же категории (магазин/аптека/выход/вход/не курить). Самый полезный для жизни тип для E: приоритизировать.

## 2. ДОПОЛНИТЕЛЬНЫЕ типы (ранг по пользе/усилию)

1. **Повторное тестирование ошибок (интервальное, Leitner 1-2-4-8 дней)** — максимальная польза, малое усилие. Слово после ошибки возвращается через 10 мин, потом завтра, через 3, 7, 21 день. Обязательно для обоих. Для E: ежедневная «очередь повторения» ограничена 10 словами.
2. **Смешанный «финальный повтор урока»** (5-7 заданий разных типов из только что пройденного) — польза высокая, усилие малое. Обязательно в конце каждого урока.
3. **Пропущенное слово во фразе** (cloze, выбор из 3-4) — высокая польза (контекст, грамматика), усилие малое. E: фразы с огласовками и переводом; A: без перевода.
4. **Верно/неверно** («מים = огонь?») — очень дёшево, подходит E как лёгкая разминка и для «сломанных» форм у A. Есть риск 50% угадывания: давать только как разогрев, в мастерство не засчитывать с полным весом (вес 0.5).
5. **Тренировка чисел** (цены, телефоны, время): слышит -> набирает цифрами на цифровой клавиатуре. Для E очень ценна в быту (рынок, автобус, врач); начинать с чисел до 20, цены в шекелях, время «половина шестого». Усилие среднее.
6. **Минимальные пары похожих букв** (ב/כ, ד/ר, ח/ה/ת, ו/ז/ן, ס/ם): «какую букву слышишь/видишь» в слове, 4 крупные кнопки. Высокая польза для обоих, малое усилие (данные — список пар слов). Для E отдельный мини-курс, 2 пары за раунд.
7. **Чтение без огласовок** (прочитай слово, выбери перевод; потом нажми «проверить» и услышь): ключ для A, для E только после уверенного чтения с огласовками (не раньше уровня A2).
8. **Род/число (m/f, sg/pl)**: «выбери форму во множественном числе», таблицы пар. Польза высокая для A, для E — только самые частые слова (дети, друзья, дни) и только выбор, без правил.
9. **Диктант**: слышит слово -> собирает из плиток (E) / печатает (A). По сути «сборка + аудио»; усилие малое, если сборка и аудио уже есть. Рекомендуется.
10. **Спринт на время** (60 с, максимум верных; только A, режим «по желанию», рекорд, а не потеря очков).
11. **Обратный ввод на экранной ивритской клавиатуре** — только A. Нужна встроенная клавиатура (системная неудобна), ввод с проверкой допускает пропущенные огласовки/пробелы; высокая польза, но усилие высокое.
12. **Самооценка уверенности перед ответом** («уверен/не уверен») — мало усилий, но усложняет UI; только для A, опционально.

**НЕ стоит для E (пожилого):** спринт на время и любые таймеры (стресс, мотор снижается с возрастом); ввод с клавиатуры (мелкие кнопки, раскладка, ошибки опечаток не равны незнанию); перетаскивание на тонких целях; трассировка буквы пальцем с оценкой «точности»; соревновательные лидерборды и «жизни/сердечки»; верно/неверно как основной контроль (угадывание); самооценка уверенности (лишнее когнитивное решение); чтение без огласовок до уверенного чтения с огласовками.

## 3. «Слово выучено» и статистика

**Ступени слова:** 0 Новое -> 1 Знакомо (показано, 1 верный ответ) -> 2 Учится (>=2 верных в разные дни) -> 3 Выучено -> 4 Закреплено (долгосрочное).
**Выучено =** все три условия:
- >=3 верных ответа подряд, из них >=1 в направлении русский -> иврит (активное) и >=1 по звуку (или в сборке);
- верные ответы минимум в 2 разных дня (интервал >=1 день: отсекает краткосрочную память);
- нет ошибок в последних 2 ответах.
**Закреплено =** «выучено» + верный ответ после интервала >=7 дней. **Сброс:** ошибка после «выучено» понижает на одну ступень, не до нуля. Для E первое ступень «Выучено» после 3 верных в 2 разных дня, без требования направления рус->иврит (его добавляется через 2 недели). Самооценка «знаю» в карточках считается за 0.5 верного ответа, если не подтверждена проверочным вопросом.

**Показатели (мотивирующие, без стресса):**
- «Слов выучено: 143 из 600» и кольцо прогресса по темам (процент выученных). Только растущие числа; никогда не показывать «потеряно».
- «Сегодня»: «Вы позанимались 12 минут, повторили 8 слов» — а не «выполнено 40% дневной нормы». Цель дня — мягкая (10 слов или 10 мин), без серии «стрик» как для A; для E «Вы занимались N дней на этой неделе» (дни недели с отметками), пропуск не обнуляет.
- Слабые слова: список «Над чем поработать» (макс. 10), называется так, а не «ошибки».
- Точность — скользящая за 7 дней, показывать только если >= 60%; иначе показывать счётчик усилий.
- Раздельно: чтение, слух, письмо (A). Динамика: график выученных слов по неделям, всегда восходящий (накопительный).
- Для A: время реакции (медиана), сравнение с личным рекордом, прогноз «до следующего уровня примерно 3 недели».
- Мотивирующие «вехи»: 25/50/100 слов, первая тема закрыта, первый экзамен — спокойное сообщение («Отлично! Вы знаете 50 слов»), без анимации и звука на весь экран по умолчанию.

## 4. Экзамены

**Экзамен по теме (E):** 15 заданий, без времени: 5 выбор иврит->рус, 3 выбор рус->иврит, 3 аудирование, 2 пары (4 пары), 2 сборка слова/фразы. Допуск: все слова темы в статусе «Учится» и выше. Порог 70%. Перепройти можно сразу и неограниченно; при повторе вопросы другие, ошибки прошлой попытки включаются в приоритете. Пройденный — «Тема освоена» (золотая звезда, без процента на карточке).
**Экзамен по теме (A):** 25 заданий: 8 выбор (рус->иврит без огласовок), 5 аудирование, 4 cloze, 3 сборка фразы, 3 род/число или грамматика, 2 пары (8). Порог 80%, один раз в сутки; не сдан — рекомендация конкретных слов для повтора. Результат считается по слову, так что провал не стирает прогресс.

**Экзамен уровня** (A1/A2/B1/B2): берёт из всех тем уровня, не менее 70% слов уровня у учащегося должны быть «Выучено».
- A1: 40 заданий, ~20 мин; A2: 50; B1: 60; B2: 70 (A-режим, огласовок нет с B1). Для E уровни A1 и A2: 30 и 40 заданий, разбивка на 2-3 сессии с сохранением, паузой и без таймера; огласовки по настройке.
- Состав: 35% лексика (выбор, пары), 20% аудирование, 20% грамматика (cloze/форма), 15% чтение (короткий текст, 3 вопроса — начиная с A2), 10% сборка фразы/диктант. Знаки A1: добавить вывески и чтение цифр.
- Порог 75% и не менее 60% в каждом разделе (чтобы нельзя было «слить» слух). E: порог 70%.
- Повтор: через 24 часа, новая выборка вопросов; после двух неудач — разбор слабых разделов и мини-курс «подтяжка», затем повтор без ограничений по времени ожидания. Результат: «Уровень A2 подтверждён» либо «Вы на 82% в пути к A2: осталось подтянуть аудирование».
- Входной тест (64 вопроса) — оставить как диагностику; не как экзамен, результат определяет стартовую тему, не «оценку».

## 5. Доступность для пользователя 70+ на планшете

- **Шрифт:** основной текст >=22 sp (по умолчанию), иврит в упражнении >=48 sp, кнопки с подписью >=24 sp; режим «Крупно» (+30%) в один тап. Никакого текста мельче 18 sp, в том числе подписей.
- **Начертание:** ивритский шрифт без засечек с чёткими огласовками (Heebo, Assistant, Frank Ruhl только для крупных заголовков); интервал строк >=1.5; огласовки не мельче 70% размера буквы.
- **Контраст:** >=7:1 для основного текста (AAA), >=4.5:1 для всего остального; цвет никогда не единственный сигнал (галочка/крестик + слово); тёмная и светлая темы; фон белый/кремовый, без градиентов и узоров под текстом.
- **Цели касания:** >=64 px (рекомендуется 72-80), расстояние между кнопками >=16 px; основные кнопки внизу экрана (достижимы большим пальцем); никаких свайпов, долгих нажатий, двойных тапов и жестов как единственного способа; подтверждение необратимых действий («Сбросить прогресс?») двумя большими кнопками.
- **Темп:** никаких таймеров в режиме E; ответ принимается по тапу, без автоперехода — вперёд только кнопкой «Дальше»; анимации <=300 мс и отключаемые; звук включается только по тапу (кроме авто-проигрывания слова один раз); сессия 5-10 минут, после раунда предложить паузу.
- **Формулировки ошибок:** «Почти! Правильно: …», «Попробуем ещё раз?», никогда «Неверно!», «Ошибка», красный крест на весь экран, резкий звук. Не использовать жаргон (cloze, дистрактор, биньян). Одна инструкция на экране, одним предложением, глаголом в повелительном наклонении («Выберите перевод»).
- **Навигация:** один главный путь «Продолжить занятие» на главном экране; не более 4 пунктов нижнего меню с иконкой и подписью; кнопка «Назад» всегда видна; выход посередине раунда сохраняет прогресс без вопросов.
- **Ввод:** никаких обязательных клавиатур для E; цифры — крупная цифровая панель; русский и иврит в UI без смешения направлений (иврит в RTL-блоке, русский в LTR, с чёткой разделительной линией).
- **Прочее:** кнопка «Повтор звука» везде; скорость речи 0.75x/1.0x; поддержка системного масштаба шрифта и режима высокой контрастности Android; без рекламы, всплывающих окон и уведомлений с давлением («Вы пропустили день!»); ориентация и экран не блокировать; проверять на реальном планшете с реальным пользователем (5 минут наблюдения важнее чек-листа).
