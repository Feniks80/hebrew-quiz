# hebrew-quiz

Набор автономных квизов для изучения иврита. Каждый файл — один HTML без сборки,
открывается в браузере, прогресс хранится в `localStorage`.

## Что где лежит

| Файл | Уровень | Слов | Назначение |
|---|---|---|---|
| `hebrew-zero.html` | A0 (с нуля) | 50 + алфавит | Для начинающих, с озвучкой и крупным шрифтом |
| `index.html` | B1 | 1408 | Инженерная терминология, базовый набор |
| `hebrew-b2-quiz.html` | B2 | 1521 | Расширенный инженерный набор |
| `hebrew-quiz-full.jsx` | B1 | 1408 | React-исходник для `index.html` |
| `audio/` | — | — | MP3-озвучка для `hebrew-zero.html` (50 слов + 22 буквы) |
| `tools/gen_audio.py` | — | — | Скрипт для пересоздания MP3 |
| `archive/` | — | — | Старые версии и прототипы |

## Как открыть

Просто открыть нужный `.html` в браузере. Никаких зависимостей и сборки нет.

## Озвучка иврита

`hebrew-zero.html` сначала пробует **системный голос иврита** (на Android —
Google TTS, на iOS — Apple голос). Если он установлен — звук живой и
естественный.

Если в системе голоса иврита нет, страница автоматически воспроизводит
**встроенные MP3-записи** из папки `audio/` — слов и алфавита (≈600 КБ
суммарно). Они звучат роботично (синтезированы локально), но всегда
работают, даже без интернета.

### Чтобы был живой голос на Android (планшет и телефон)

Один раз настроить:

1. **Настройки → Общие настройки → Язык и ввод → Преобразование текста в речь**
   (на разных оболочках путь может слегка отличаться).
2. Выбрать движок **Google** (или Samsung на Samsung-устройствах).
3. Открыть его настройки (⚙) → **Установить голосовые данные** → выбрать **עברית (Hebrew)**.
4. Закрыть и снова открыть Chrome.

Громкость во время прослушивания — **медиа** (Media), а не звонка.
Если на странице сверху появилось оранжевое предупреждение «нет голоса для
иврита» — значит, шаг выше ещё не сделан.

На iPhone/iPad: **Настройки → Универсальный доступ → Устный контент → Голоса
→ Иврит**, выбрать голос и подождать загрузки.

### Как пересобрать MP3-записи

Записи сгенерированы локально через `espeak-ng` + `mbrola hb2`. Чтобы
пересоздать (например, после правки списка слов), на Linux:

```bash
sudo apt install espeak-ng mbrola mbrola-hb2 ffmpeg
python3 tools/gen_audio.py
```

Скрипт `tools/gen_audio.py` хранит список слов и букв; он должен
соответствовать массивам `WORDS` и `LETTERS` в `hebrew-zero.html`.
