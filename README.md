# Учим иврит

Приложение для изучения иврита русскоязычными: от алфавита до инженерной
терминологии. Работает без интернета, без регистрации и без установки
дополнительных программ.

© Shimon Donen, 2026

## Как запустить

| Где | Как |
|---|---|
| **Компьютер** | Скачать один файл `hebrew-quiz.html` и открыть двойным щелчком. Всё (слова, шрифты, грамматика) находится внутри файла. |
| **Android** | Установить APK (собирается в GitHub Actions, см. ниже). Внутри та же страница, интернет не нужен. |
| **Сайт** | Открыть `index.html` с любого веб-сервера; можно добавить на главный экран как приложение (PWA). |

Озвучка использует голос, установленный на устройстве (на Android — «Синтез
речи Google» с пакетом иврита). В настройках приложения есть проверка голоса
и кнопка перехода к установке.

## Что внутри

Около 5000 слов и фраз в 17 темах, все с огласовкой, русской транскрипцией с
ударением и переводом.

- **Начало:** алфавит, письменные (рукописные) буквы, первые 50 слов, основа
  A1 (числа, время, вопросы, местоимения), вывески и надписи.
- **Слова по темам:** 100 слов с картинками, здоровье, магазин, дом, город,
  люди, семья и праздники, учреждения и документы.
- **Говорим:** разговорник (телефон, врач, аптека, такси, мастер, соседи,
  экстренные случаи) и глаголы со связками.
- **Грамматика:** 31 урок A1–B1 с таблицами, примерами и упражнениями;
  таблицы спряжения 60 глаголов с тренировкой форм.
- **Продвинутый уровень:** бытовой B2, тест по идиомам и сленгу.
- **Инженерный иврит:** стройка, сборный и преднапряжённый железобетон,
  чертежи, рабочие фразы для площадки, совещаний и переписки.
- **Проверка:** тест уровня (64 вопроса), работа над ошибками, статистика.

Виды упражнений в каждой теме: карточки, выбор перевода (в обе стороны), на
слух, «собери слово / фразу», найди пару, экзамен. Таймеров нет.

Настройки: простой или полный режим, огласовки вкл/выкл, размер текста,
светлая и тёмная тема, скорость речи, перенос прогресса кодом на другое
устройство.

## Устройство проекта

```
content/            источник правды: словари, грамматика, тесты (JSON)
  decks/*.json      темы
  patches/*.json    исправления к темам (применяются при сборке)
  reports/          отчёты аудита содержимого
tools/build.py      content/ → data/*.js + service-worker.js
tools/build_single.py   всё приложение → один файл hebrew-quiz.html
tools/validate_content.py   проверка словарей
js/, app.css, index.html    само приложение (без фреймворков и сборщиков)
data/               сгенерировано, руками не править
android-app/        обёртка WebView с мостами к системной озвучке и хранилищу
archive/            прежние версии и старые генераторы
```

Изменить или добавить слова:

```
# отредактировать content/decks/<тема>.json (формат — content/SCHEMA.md)
python3 tools/validate_content.py
python3 tools/build.py
python3 tools/build_single.py
```

## Android-приложение

Workflow `.github/workflows/build-apk.yml` собирает страницу в один файл,
кладёт её внутрь APK и публикует результат как артефакт сборки.

Чтобы обновления ставились поверх без удаления, нужен постоянный ключ подписи:
секреты репозитория `KS_B64`, `KS_PASS`, `KEY_ALIAS`, `KEY_PASS`. Если их нет,
APK подписывается отладочным ключом и релиз не публикуется.

Прогресс в приложении дублируется в постоянное хранилище Android и переживает
очистку кэша.
